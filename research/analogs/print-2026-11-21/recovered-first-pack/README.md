Источники для проверки принадлежности:

- [NOHRD StepBox](https://www.nohrd.com/de/nohrd-stepbox-all-in-one.html), [медиатека NOHRD](https://media.nohrd.com/). Точные URL каждого из пользовательских вложений в доступных данных не сохранены.
- [Technogym Bench](https://www.technogym.com/en-US/product/technogym-bench_DGY100.html). Присланные DGY100-файлы относятся к подборке автора; исходный адрес каждого файла не восстановлен.
- [FITBENCH FREE](https://fitbench.com/products/fitbench-free), [прежняя карточка без инвентаря](https://fitbench.com/products/fitbench-free-naked). Адрес каждого DSC-файла не установлен.
- [Прежняя ссылка на полный каталог Technogym Bench](https://www.technogymkr.com/web/catalog/04_catalog_technogym_bench.pdf). Прямое скачивание 21.11.2026 вернуло 403. Сохранённая ранее выборка `Technogym_Bench_inventory_pp08-11.pdf` включена в эту папку, 4 страницы. Она не выдаётся за полный каталог.

Полный загруженный каталог и видео не обнаружены в доступных локальных файлах. Это ограничение сохранения; утверждение прошлого чата «видео сохранено» само по себе не доказывает наличие файла в GitHub.
