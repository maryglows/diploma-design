# Исследование

Текущее исследование нужно вести от пользователя и движения к требованиям конструкции.

Для каждой группы собрать: цель активности, условия дома, положения тела, опоры и усилия, диапазоны размеров, ограничения и источники. Различать результаты наблюдений, собственные измерения, справочные данные и гипотезы.

Начать с таблицы в [sources.md](sources.md) и шаблона [карточки движения](../templates/movement.md). Ранний анализ аналогов сохранён в archive/ и не определяет окончательную аудиторию.

Фотографии в analogs/photos/ получены из ранее подготовленного набора. Происхождение указано в Sources.txt. Наличие изображений не означает передачу прав на их публикацию. Для публичной защиты подписывать источники; перед открытием репозитория проверить права на материалы.
