# Эскизы и предварительное задание

Сравниваем две компоновки для одного изделия, которым по очереди пользуются дети, молодые взрослые и пожилые.

| Вариант | Что проверить в черновом макете |
|---|---|
| **Скамья** с постоянным сиденьем, раздельным хранением и собственным хватом | Посадку, доступ к инвентарю и место для подхода. |
| **Напольный шкаф** со складным сиденьем на двух передних ножках | Свободное место перед шкафом, доступ в разных положениях сиденья и расположение опор. |
