# Эскизы и предварительное задание

Сравниваем две компоновки для одного изделия, которым по очереди пользуются дети, молодые взрослые и пожилые.

[Паспорт тренажёра](passport.md) связывает обе компоновки с решениями автора. Для скамьи готовы [кадр перед подъёмом пяток](bench-grip/start-position.png) и [печатный лист для проверки хвата](bench-grip/fit-sheet.pdf).

- **Скамья** с постоянным сиденьем, раздельным хранением и собственным хватом. Проверить посадку, доступ к инвентарю и место для подхода.
- **Напольный шкаф** со складным сиденьем на двух передних ножках. Проверить свободное место перед шкафом, доступ в разных положениях сиденья и расположение опор.
