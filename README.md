# Диплом по промышленному дизайну

Проект компактного домашнего тренажёра с мебельной функцией и хранением инвентаря.

Сейчас задача — выбрать рабочую идею, показать, как ею пользуются дома, и проверить её черновым макетом. **25 декабря 2026** — промежуточный просмотр. **К концу мая 2027** должны быть готовы чистовой макет, большой планшет, презентация и проработанная концепция.
