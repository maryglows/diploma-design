# Диплом: модульный спортивный тренажёр с мебельной функцией

Рабочее пространство дипломного проекта по промышленному дизайну. Название предварительное.

**Сейчас:** исследование пользователей, движений и необходимого пространства. Форма изделия ещё не выбрана. До следующего этапа нужно подготовить анализ, а не закреплять вариант лавочки или шкафа.

**Результаты работы 24–25 октября:** [три A3, исследование Word, итоговая презентация и сообщение преподавателю](docs/work-session-2026-10-25.md). Актуальная презентация — v2 на 30 слайдов. Рабочая ветка сохранения: `codex/project-work-2026-10-25`; при продолжении проверить Git и прочитать CURRENT.md.

## С чего начать

1. Прочитать [описание проекта](PROJECT.md) и [текущее состояние](CURRENT.md).
2. Открыть [задачи](TASKS.md), выбрать одну ближайшую задачу.
3. Проверить [выводы последней консультации](meetings/reviews/teacher-discussion-01-review.md) по [исходной расшифровке](meetings/raw/teacher-discussion-01.md).
4. Для работы с агентом использовать [AGENTS.md](AGENTS.md). Эти инструкции работают при доступе агента к репозиторию; одна ссылка не подключает закрытые файлы автоматически.

Для новых чатов в одном проекте Codex: [однократная привязка репозитория и перенос контекста](docs/codex-project.md). При корректно открытом репозитории агент читает правила сам; повторять длинный стартовый промпт не требуется.

## Как пополнять

Новый разговор сохранить отдельным файлом в `meetings/raw/`. Указать дату самой встречи, если она известна. Дату загрузки не выдавать за дату встречи. Затем попросить агента составить разбор, обновить задачи и текущее состояние. Проверить результат и сохранить изменение с понятным описанием.

Архивные материалы отражают раннюю идею для аудитории 18–30 лет. После консультации исследование расширено. Старые цены и характеристики аналогов перед повторным использованием нужно проверить по первоисточникам.

Этот набор собран из доступных материалов переписки 22.10.2026. Он не содержит всех возможных личных файлов автора. Само распаковывание набора не создаёт репозиторий на GitHub: порядок загрузки описан в инструкции.
