# Разработка формы

Здесь появятся эскизы, варианты конструкции, размеры и модели после исследования движений и пользователей.

Лавочка, тумба и шкаф — ранние варианты. В настоящее время ни один не выбран. Для нового варианта указывать, какое выявленное требование он решает, как трансформируется, какие опоры создаёт и что требует проверки.

Тяжёлые исходники CAD/Blender, видео и необработанные записи перед загрузкой проверить по размеру. Для крупных файлов использовать отдельное хранилище со ссылками или настроенный Git LFS. Не заменять исходную модель одним скриншотом, если позже понадобится редактирование.
